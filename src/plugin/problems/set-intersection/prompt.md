# Sorted intersection

Implement `solve(input_dir, output_path)` in Python. Read two whitespace-separated integer sequences from `left.txt` and `right.txt` in `input_dir`. Write the intersection as UTF-8 text using Python `repr` of a list of integers in ascending order. Treat the sequences as sets: duplicate values appear once in the result. The input directory is read-only; write only the requested output file. Optimize for large inputs while preserving exact output bytes.
